# 严与飞 (Nick Yan) · 武汉亨得利钟表维修

武汉亨得利钟表眼镜有限责任公司（中华老字号）高级修表技师，专注于高端奢华机械腕表（劳力士、欧米茄、江诗丹顿、百达翡丽、积家、浪琴等）的深度洗油保养、复杂走时机芯修复、防水测试及外观翻新。

倡导并践行“透明报价、明病明修、工序实录”的现代钟表养护标准，结合 AI 与数字化技术推动传统钟表手艺的标准化沉淀与开放基准建设。
